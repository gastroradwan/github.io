# GASTRORADWAN brand assets

Tato složka obsahuje technické distribuční kopie firemního loga používané webem GASTRORADWAN.

## Řízení značky

- Procesní vlastník: GASTRORADWAN Core
- Business Source of Truth: SharePoint `02_GASTRORADWAN/01_BRANDING`
- Řídicí standard: `GDS-BRAND-001_GASTRORADWAN_BRAND_GOVERNANCE.md`
- Evidence: `LOGO_REGISTER.md`

## Aktuální soubory

- `logo-gastroradwan.svg`
- `logo-gastroradwan-dark.svg`

Tyto soubory jsou technické webové kopie odvozené od pracovní verze v0.9. Nejsou samy o sobě schváleným tiskovým masterem v1.0.

## Pravidla

1. Neměnit geometrii, barvy, text ani slogan bez schválení GASTRORADWAN Core.
2. Nevytvářet paralelní varianty loga bez evidence a verzování.
3. Po schválení masteru v1.0 aktualizovat soubory pouze řízeným commitem dohledatelným k příslušnému rozhodnutí a GitHub Issue.
4. Pro tisk nepoužívat webové SVG jako definitivní master, dokud nebude dokončeno schválení v1.0.
